# PVM: Proxmox Virtual Machine

This repository is made possible thanks to Universal Blue and their [image-template](https://github.com/ublue-os/image-template). Go check out their amazing work!

## Description

PVM represents a set of scripts to build custom VM images based on Fedora CoreOS and deploy them on a Proxmox node. The intention is to deploy the most ideal VM operating system possible for hosting Docker/Podman containers in a homelab or production environment. 

> Note: This repo is a work in progress and not ready for deployment quite yet.
